# Hi, I'm Shihab Hossain 👋

**Aspiring SQA Engineer** · CSE student at Port City International University (CGPA 3.88) · Chattogram, Bangladesh

I came to QA from development. Building web apps with Python and Django showed me how bugs get in: unclear requirements, untested edge cases and rushed changes. Now I focus on finding them before users do, and I'm learning to automate that work with Python, Selenium and Playwright.

🎯 **Open to SQA internships and junior QA roles.**

## 🧪 What I work on

- **Manual testing:** test scenarios, test cases, execution and clear, reproducible bug reports
- **Test design:** boundary value analysis, equivalence partitioning, functional, regression, smoke and sanity testing
- **Process:** SDLC and STLC
- **Automation (learning):** Python, pytest, Selenium WebDriver, Playwright, Page Object Model, GitHub Actions
- **API & data:** Postman, SQL for backend data checks
- **Also:** C, C++, data structures and algorithms
